# 💰 Expense Tracker

A clean, responsive web application for managing personal finances. Track daily expenses, categorize transactions, and get instant insights into spending habits with real-time totals and persistent storage.

## 🚀 Live Demo
> **[View Live Demo](https://your-username.github.io/Expense-Tracker/)** *(Update with your deployed link)*

---

## ✨ Features
- **📊 Real-time Dashboard**: Displays total transactions count, total money spent, and breakdown by category.
- **➕ Add Expenses**: Input description, amount, category (Food, Travel, Rent, Bills, etc.), and transaction date.
- **📜 Transaction History**: Chronological view of all recorded expenses.
- **💾 LocalStorage Persistence**: All your data is saved in your browser, so you never lose records on page refresh.
- **⚙️ Data Management**: Easily reset or clear all records from the settings panel.

---

## 🛠️ Tech Stack
- **HTML5**: Semantic document structuring.
- **CSS3**: Responsive layout, CSS Flexbox, custom form styling, and transitions.
- **JavaScript (ES6+)**: DOM manipulation, event-driven state updates, and LocalStorage API.
